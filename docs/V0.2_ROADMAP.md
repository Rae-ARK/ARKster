# ARKster v0.2 — Arc support, UX polish, and list preferences

## Summary
v0.2 builds on the v0.1 foundation (folder scan, library, reader) by adding arcs, per-fiction pagination preferences, UI refinement, and incremental rescan optimizations.

## Features

### 1. Arc detection and display
- Detect arc folders by pattern matching (`Arc`, `Volume`, `Book` prefixes in folder names).
- Parse arc-specific cover images (`cover.*` inside arc folders).
- Add `Arc` entity to Room schema.
- Update novel detail screen to show tabbed view: "All Chapters" (default) vs. arc tabs.
- Chapters grouped by arc with visual separation.

### 2. Per-fiction pagination preferences
- Add `chapter_list_page_size` preference to `PreferencesManager` but track per-novel in Room.
- Novel detail screen shows pagination controls (10/20/50/100 items per page).
- Persist user's choice in Room per novel.
- UI shows "page N of M" indicator.

### 3. Chapter override editor (graceful degradation)
- Add "Edit" action on novel detail screen.
- In-app editor allows users to:
  - Reorder chapters (drag-drop or up/down buttons).
  - Rename a chapter title.
  - Mark a chapter as a volume/arc boundary.
- Persist overrides as a separate Room table (`ChapterOverride`) layered on top of scanned data.
- Override symbol or badge appears on chapters that have been edited.

### 4. Incremental rescan optimization
- Store scan fingerprints for each novel folder (uri, lastModified, size).
- On rescan: compare fingerprint to Room. If unchanged, skip reparsing.
- Only update chapters for novels that have changed.
- Rescan should feel significantly faster on large libraries.

### 5. UI / UX polish
- Add app theme selector (Light / Dark / Warm Paper per Material 3).
- Better error states and logging on the library screen.
- Progress indicator during scan (e.g., "scanning 12/40 novels...").
- "Continue Reading" carousel/section on library home showing last-read novels.
- Basic book search (filter novels by title/author in real-time).

### 6. Reading progress improvements
- Track page/scroll position per chapter more reliably.
- "Continue" button on library to jump to last-read chapter.
- Mark novels as "In Progress" vs. "Completed".

## Implementation roadmap

### Phase 1: Data model updates
1. Add `Arc` entity and `ArcDao`.
2. Add `ChapterOverride` entity and `ChapterOverrideDao`.
3. Add scan fingerprint table for incremental optimization.
4. Migration strategy for existing v0.1 users.

### Phase 2: Scanner enhancements
1. Implement arc folder detection in `ScannerImpl`.
2. Implement fingerprinting and incremental rescan logic.
3. Add override layering (merge scanned chapters + user overrides).

### Phase 3: UI screens
1. Update `NovelDetailScreen` to show arc tabs and pagination.
2. Add chapter override editor modal or screen.
3. Add library search filter (reactive).
4. Add "Continue Reading" section to home screen.
5. Theme selector in settings.

### Phase 4: Polish
1. Test on various folder structures (flat, nested arcs, mixed).
2. Stress-test with 50+ novels and 1000+ chapters.
3. Refine error messaging and edge case handling.
4. Optimize scan speed and database queries.

## Success criteria
- Arc detection works for common naming patterns (Arc, Volume, Book, Part).
- Pagination preference is saved per novel and persists across sessions.
- Rescan is noticeably faster on unchanged folders.
- Override editor works smoothly without data loss.
- "Continue Reading" carousel is visible and functional.
- All Material 3 themes render correctly.

## Known unknowns
- How many novels/chapters before Room queries become slow? May need indexing strategy.
- Should arc detection be automatic or require user hint? (v0.2 assumes automatic with override option.)

## Out of scope for v0.2
- EPUB/PDF support (v0.3).
- Network metadata provider (v0.3).
- Export/backup functionality.
- Sharing features.
